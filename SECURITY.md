# Security

Trackpad Whiteboard is a Windows desktop app for one user. It has no accounts and no server.

## Report a problem

Open a [GitHub issue](https://github.com/OllieRumbol/TrackpadWhiteboard/issues). Describe the problem in general terms, and do not post details that show how to exploit it. If you need to share those details, say so in the issue.

## Supported versions

Only the latest code on `main` gets fixes.
